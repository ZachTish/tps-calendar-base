# TPS Calendar Base 1.0.0 — Whole-note Calendar authoring

Calendar creates whole Markdown notes for toolbar, range, template-drop, and external-event actions. In the regular Base note route, a `kind == task` creation default becomes frontmatter on a whole note; saved legacy task-mode settings and `task.*` selection filters cannot route creation into a checkbox line. Native Calendar records remain whole Markdown notes with GCM-owned canonical metadata. Dropping an existing unscheduled note schedules that note. New external-event notes receive active Base frontmatter defaults; reused notes do not receive those defaults.

The **Initial calendar create**, **Task item destination**, and **Dedicated task note path** controls are removed. Legacy saved keys are retained but ignored by Calendar authoring. Historical inline task lines remain visible and navigable, while Calendar drag scheduling, move/resize, task-edit context handoff, and direct task-line creation fail closed. This is a major version because formerly supported task-line authoring and related settings are removed. No automatic migration, startup scan, or repair changes existing notes. Minimum Obsidian: **1.10.0**.

Tested in **Obsidian Plugin Test Vault** and ready for the user's BRAT pull. Production has not been changed.
