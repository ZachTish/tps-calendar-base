# TPS Calendar Base 0.7.0

This backward-compatible minor release lets Calendar use GCM's shared template identity rule. Root-level templates can be recognized by tag or property key/value while exact configured template paths and the legacy folder fallback remain intact.

Minimum Obsidian: 1.10.0. Metadata-defined templates require TPS Global Context Menu 1.42.0.
