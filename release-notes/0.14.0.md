# TPS Calendar Base 0.14.0

Calendar task creation now recognizes an explicitly selected note with `kind: note` and `noteKind: daily` as a Daily Note destination, even when its path differs from the event date. Tasks go in the Scheduled section using existing ordering. Both properties are required for this new route; keys/values are case-insensitive and surrounding whitespace is ignored.

Legacy path, kind and tag recognition remains supported. Ordinary note/task subtypes retain ordinary placement. No settings/defaults, automatic destination selection, API version changes, or note migration are introduced. The selected note's metadata remains unchanged.

Update GCM to 2.4.0 for shared Daily Note creation, date lookup, reconciliation and Navigator integration. This Calendar release supplies the matching task-placement behavior.

This is a minor release because it adds backward-compatible two-level Daily Note support. Minimum Obsidian remains **1.10.0**.
