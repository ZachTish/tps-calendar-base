# TPS Calendar Base 0.8.3

Embedded Daily Note calendars now open on the date of the note that contains them instead of retaining a stale saved date or beginning several days before the host day.

- **Use host note date** now resolves a render-scoped Markdown host even when Obsidian's Base controller exposes the embedded `.base` file first. Calendar retries host detection at the first runnable update, closing the early-mount race that could leave `tps_currentDate` visible.
- Host date resolution uses the configured host-note date field first, then the Daily Note filename, with render-provided path and date attributes as scoped fallbacks. It never follows an unrelated active note.
- Embedded multi-day views, including full seven-day and Week views, start with the host day in their first visible column. Dedicated Calendar tabs retain their centered focal-day behavior.
- Repeated refreshes of the same host do not undo explicit Previous, Today, Next, date-picker, or protocol navigation. Moving to a different host Daily Note applies that note's date once.
- Markdown rendering now supplies its source path directly. The direct-render API also accepts the backward-compatible optional `hostNotePath` option for custom embed callers.

This is a backward-compatible correctness fix with no settings, Base-definition, note-data, command, or persistence migration. Minimum supported Obsidian remains 1.10.0.
