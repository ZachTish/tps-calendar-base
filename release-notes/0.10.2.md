# TPS Calendar Base 0.10.2

This patch adopts the shared TPS exact-template-tag lifecycle for Calendar-created notes and protects tagged template
sources from Calendar's automatic detached-link cleanup.

- With TPS Global Context Menu 1.50.0 or newer, Calendar event templates, external-event meeting templates, and the
  standalone Daily Note fallback remove only the exact top-level `template` tag from each new copy before creation.
- Calendar rechecks the created copy after Templater and fails closed before applying event metadata if the result cannot
  be verified. Unrelated YAML tags, their order, and body `#template` text are preserved; the source template is unchanged.
- A raced or reused file is not sanitized merely because it occupies the requested path. Automatic detached parent/child
  link cleanup checks the shared guard at both its file and atomic-frontmatter boundaries; explicit link actions remain
  available.
- Missing older GCM providers retain Calendar's previous behavior. Existing notes are not rewritten retrospectively, no
  setting or Calendar public API is changed, and minimum supported Obsidian remains 1.10.0.

Validation passed the focused creation, source-preparation, post-Templater, compatibility, race-ownership, and automatic-link-cleanup regressions; all 21 package-declared test files; TypeScript; diff checks; and the mandatory separate production-mode build. Obsidian 1.13.7 reloaded the isolated test vault with Calendar 0.10.2 beside GCM 1.50.0. The shared Daily Note copy removed only the exact template marker while preserving unrelated tags and body content, outbound Calendar automation remained disabled, temporary notes were archived, and production was not accessed. This release is ready for a BRAT pull after publication.
