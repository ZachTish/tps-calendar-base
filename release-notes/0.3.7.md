# TPS Calendar Base 0.3.7

## Intent

Make the count shown by Calendar trustworthy for dynamic day-based views without editing unsupported Obsidian-owned DOM.

## Changes

- Added a Calendar-owned visible-event count that follows FullCalendar's exact half-open visible range as the user navigates.
- Counts local-note, inline-task, and external event cards whose intervals overlap that range.
- Excludes auxiliary-date and archived-warning markers, which are overlays rather than rendered event cards.
- Uses the configured default duration for entries without an explicit end.
- Removed all private Base-header result-count selector probing and text mutation.
- Exposed the count as a polite accessible status with singular/plural labeling.

## Compatibility and migration

- Backward-compatible patch; no settings, commands, API, Base schema, or note-data migration.
- Minimum supported Obsidian version: 1.10.0.
- Obsidian's native Base count continues to describe the Base query. The new Calendar count explicitly describes only events visible in the current Calendar range.

## Validation

- Focused exact-range coverage includes one-day and three-day navigation, strict boundaries, spanning events, missing-end duration, mixed local/inline/external entries, marker exclusion, invalid data, and 23-hour/25-hour daylight-saving days.
- All 121 release-declared tests, three separate containment checks, and TypeScript passed. A separate production-mode build deployed the final versioned artifacts to the test vault.
- After `Reload app without saving`, the permanent three-record QA Base showed `0 visible events` for July 30–August 1 and `3 visible events` for July 16–18 while its native Base-query count remained three. Today restored the original July 31 state, and no note or setting was changed.
- Tested only in `Obsidian Plugin Test Vault`; production was not changed. Ready for the user's BRAT pull after test-vault acceptance.

## Known limitations

- The Calendar-owned count appears after FullCalendar reports its first exact visible range.
- Continuous-scroll mode does not expose a single FullCalendar visible range, so it does not show this count.
- Obsidian's separate native Base-query count may differ by design when the Base query spans dates outside the visible Calendar range.
