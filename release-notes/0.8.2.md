# TPS Calendar Base 0.8.2

Short timed events are readable again inside compact Daily Note calendars without changing their real schedule.

- Embedded time-grid calendars now apply an 18px visual floor to both timed cards and condensed time rows. A real 15-minute event therefore keeps its 15-minute start/end data while retaining enough card height for one title line, and an ordinary 30-minute event does not falsely overlap the next 30-minute interval.
- Dedicated Calendar tabs keep exact proportional geometry. Standard Base embeds, continuous embeds, and embeds rendered through Calendar's plugin API share the same compact-host behavior.
- The floor changes no note, Base, setting key, command, public API, drag payload, or resize payload. Existing `minEventHeight` values still control missing-duration fallback cards, but embedded timed cards cannot render below the 18px host floor.

This is a backward-compatible rendering fix with no migration. Minimum supported Obsidian remains 1.10.0.
