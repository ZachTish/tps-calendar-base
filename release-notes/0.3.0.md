# TPS Calendar Base 0.3.0

This minor release makes Calendar settings easier to scan without exposing every option at once.

## User-visible changes

- Replaces the long settings accordion with five shallow destinations: Rules & creation, Calendar sources, View & navigation, Appearance, and Advanced.
- Keeps the selected destination visible through settings rerenders and uses a compact horizontal route strip on mobile.
- Adds a direct handoff to Controller settings for Controller-owned calendar sources.
- Replaces raw event-style-rule JSON with readable cards and a visual Add/Edit/Duplicate/Delete/reorder editor that preserves existing rule IDs and operators.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0. Desktop and mobile are supported.
- Existing setting keys and defaults are unchanged; no settings migration is required.
- Base visibility and creation rules are still authored through Base filters. Stored style-rule icons remain supported but are not edited by the visual rule editor.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.

## Validation

- Focused settings-surface checks passed 9/9; the exact clean release snapshot passed the complete declared suite, 76/76.
- The required separate production-mode build passed and deployed the exact release artifacts to `Obsidian Plugin Test Vault`.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**. All five destinations, the Controller handoff, mobile route layout, keyboard focus, and visual style-rule editor were checked in the isolated test vault without saving settings.
- Calendar had no runtime `data.json` before or after deployment.
