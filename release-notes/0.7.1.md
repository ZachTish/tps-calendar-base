# TPS Calendar Base 0.7.1

This backward-compatible patch keeps native calendar cards readable. Controller-owned occurrence records may intentionally store a clickable associated-note link in `title`; Calendar now presents their plain `eventTitle` on the block instead of showing link markup.

The underlying link property and associated-note routing remain unchanged. Explicit custom and formula title configurations continue to override the native label.

Minimum Obsidian: 1.10.0.
