# TPS Calendar Base 0.6.0

This backward-compatible minor release adds a native-record presentation path. In native mode the Calendar consumes already-filtered file rows from core Bases and no longer synthesizes inline tasks, fetches external feeds, or runs its custom query evaluator.

Minimum Obsidian: 1.10.0. Native mode requires Controller 0.11.0 and GCM 1.38.0.
