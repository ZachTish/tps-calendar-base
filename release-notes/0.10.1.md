# TPS Calendar Base 0.10.1

This patch restores centered selected-day placement in embedded multi-day calendars.

- **Start on host note day → Use host note date** still resolves the containing Markdown or Daily Note, but that date is now the selected focal day instead of the first visible column.
- A three-day view for September 2 renders September 1–3. Initial placement and later Today, picker, Previous/Next, responsive, and remount flows share the same centered range math.
- Even-sized ranges keep their established earlier-middle position. Full Week views retain configured weekday alignment.
- Explicit filter-derived ranges remain start-anchored to their exact lower bound.
- No setting, Base definition, saved date, event, note, command, or public API is migrated. Minimum supported Obsidian remains 1.10.0.

Validation passed 60/60 focused date-range, host, protocol, view-setting, and command checks plus the complete 253/253 checks across all 21 package-declared test files. The full suite's production build deployed the candidate to the isolated test vault. After `Reload app without saving` in Obsidian 1.13.7, an embedded three-day Calendar anchored to September 2 rendered September 1–3 with September 2 selected in the middle. The temporary fixture was moved directly to `_archive`, the original TPS Home layout and sidebars were restored, and production was not accessed.

This release was tested in the isolated Obsidian Plugin Test Vault and is ready for the user's BRAT pull.
