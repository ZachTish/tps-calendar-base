# TPS Calendar Base 0.4.5

## Intent

Restore mobile event dragging by assigning the long-press gesture to one interaction owner.

## Changes

- FullCalendar is now the sole owner of touch event dragging on mobile. Event cards no longer receive browser-native `draggable` behavior there, preventing iOS/WebView file dragging from canceling the calendar move gesture.
- Native event-card context menus are desktop-only so a touch-generated `contextmenu` cannot open during FullCalendar's drag delay. Mobile's existing single-tap menu and quick double-tap open paths remain unchanged.
- Desktop event drag-out still exports the same Obsidian file, plain-text path, and `obsidian://open` payloads, and desktop right-click behavior is unchanged.
- `touchcancel`, repeated touch starts, and component teardown now clear the haptic timer and mobile gesture-hidden state.

## Compatibility and migration

- Backward-compatible patch; no settings migration, command change, Base-schema change, plugin API change, or note/task data migration.
- Minimum supported Obsidian remains 1.10.0.

## Validation

- The focused mobile gesture suite covers all desktop/mobile and ordinary/auxiliary policy combinations, verifies the policy is applied to native drag and context-menu listeners, preserves both standard and continuous FullCalendar long-press wiring, and covers touch-cancel/unmount cleanup.
- All 179 declared Calendar tests, TypeScript, the suite's production build/deploy, the mandatory separate final production build, and byte-for-byte source/test-runtime artifact comparison passed.
- Obsidian 1.13.6 completed a full `Reload app without saving` in the isolated test vault. Calendar re-registered its command and the existing `TishOS Phone Calendar QA` three-day Base rendered successfully after reload. Physical iOS/WebView dragging remains the user's post-release acceptance check rather than an automated-device claim.
- Test-vault state is preserved. Production is not accessed.

## Known limitations

- Mobile event moving requires a long press before movement so ordinary vertical scrolling remains available.
- Continuous mode uses independent day calendars. Same-day moves use the repaired gesture; cross-day movement between separate continuous-day calendars remains unsupported.
- Calendar events inside a zoomed Obsidian Canvas still depend on Canvas touch-coordinate behavior and are not claimed by this general mobile fix.
