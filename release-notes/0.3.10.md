# TPS Calendar Base 0.3.10

## Intent

Make every displayed calendar day follow the user's selected date and the Base view's actual range semantics.

## User-visible fixes

- Manual two-through-seven-day views use the selected/saved date as the first visible day. A Friday selection in `3d` now renders Friday through Sunday.
- Full seven-column weeks align to the configured first weekday. Responsive partial weeks retain the selected day, and all week Previous/Next actions advance seven local calendar days.
- Explicitly bounded filter ranges retain their exact inclusive columns. Entry-derived filter-based views recalculate `2d` → `6d` → month as matching data changes without jumping the selected day.
- Today, date-picker/public jumps, and Previous/Next stay within explicit navigation bounds. Adjacent-month navigation no longer skips February when invoked from January 31 or March 31.
- Delayed `tps_currentDate` persistence snapshots the intended local day at the time navigation occurs.

## Compatibility and migration

- Minimum supported Obsidian version remains 1.10.0.
- No settings, Base-schema, command, plugin-API, or note-data migration is required.
- Existing manual multi-day `tps_currentDate` values are intentionally reinterpreted as the first visible day instead of the midpoint. The saved value is unchanged, but an existing visible range may shift forward on first load.

## Validation

- Behavioral coverage verifies manual start anchoring, Monday/Sunday week alignment, responsive partial weeks, DST-safe seven-day steps, explicit-range preservation, bounded navigation, adjacent-month arithmetic, call-time persistence snapshots, and live data-derived `2d` → `6d` → month transitions.
- All 134 tests passed, including three contained-workspace checks, followed by TypeScript and the required separate production-mode build.
- The final 0.3.10 runtime was deployed only to `Obsidian Plugin Test Vault` and reloaded in Obsidian 1.12.7.
- `Inbox/TishOS Phone Calendar QA.base` rendered Jul 31–Aug 2, Previous/Next moved one day, and Today restored Jul 31. Exact filter fixtures rendered Jul 31–Aug 1 and Jul 31–Aug 5. The full week rendered Mon Jul 27–Sun Aug 2, Next rendered Aug 3–9, and the constrained Markdown embed retained Fri Jul 31 as its first of two columns.
- Fixture dates were restored, no outbound automation was enabled, and production was not accessed.

## Known limitations

- Exact six- or seven-day explicitly bounded filter ranges intentionally remain dense in very narrow embeds. Use a shorter bound or a manual responsive view when fewer simultaneous columns are preferred.
