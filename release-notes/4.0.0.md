# TPS Calendar Base 4.0.0 — Remove unused Calendar configuration

Six unused global options are removed from types, defaults and normalization: `syncIntervalMinutes`, `initialCreateMode`, `taskCreateDestination`, `taskCreateTargetPath`, `syncOnEventDelete` and `previousStatusKey`. The nonfunctional **Prev Status Key** mapping disappears from Advanced. Current Base creation defaults remain authoritative; none of these old global destination values were consulted by the current writer. Existing note properties are not renamed or removed.

The existing settings-save queue omits these six keys from its fresh merged payload. Feed settings, visibility/dismissal state, stored controller identity, unrelated extension fields and concurrent current preferences remain preserved. The five destinations remain **Rules & creation** (default), **Calendar sources**, **View & navigation**, **Appearance**, **Advanced**; no new disclosure or route is added.

## Compatibility and migration

This is a major release because legacy persisted settings are removed from the supported configuration contract. Minimum Obsidian remains **1.10.0**. Existing functioning settings, commands and workflows retain their owners. Retired keys are omitted by existing settings-save paths; no new startup save, note rewrite, watcher, poller, repair loop or cleanup service is introduced. Credentials, execution state and migration markers remain protected.
