# TPS Calendar Base 0.8.1

Native calendar events now keep their real duration when a mixed Base view points its duration column at a task-only field such as `timeEstimate`.

- An authored duration/end value and a per-view fixed duration remain authoritative.
- When those are absent, only a GCM-verified native `calendar-event` may fall back to canonical `durationMinutes`, then a valid canonical `end`.
- Task rows, ordinary notes, raw `kind` lookalikes, legacy storage, and unavailable or incompatible GCM providers retain their prior fallback behavior.
- Canonical intervals are explicit, so 15-, 60-, and 180-minute events remain proportionally sized even when a condensed mobile view sets **Fallback event height** to zero.

This patch changes no Base definition, record, setting, command, or public API. GCM native-record API v2 or newer is required only for the canonical native-event fallback. Minimum supported Obsidian remains 1.10.0.
