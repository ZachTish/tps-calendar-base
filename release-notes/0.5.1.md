# TPS Calendar Base 0.5.1

## Intent

Make a TishOS Calendar widget tap reliably open the exact Base view and local day on mobile, including immediately after app switching or cross-device sync.

## Changes

- Follows the workspace leaf Obsidian actually activates after opening the Base fragment instead of forcing the original leaf back to the foreground.
- Boundedly waits for the exact Base file and named `calendar` view to materialize, rereading the adapter-backed file on every attempt rather than trusting a potentially stale metadata cache.
- Allows the widget's exact day to be applied as transient, non-persisting presentation state even when the Base's ordinary manual navigation is explicitly bounded.
- Adds stage-specific, content-free diagnostics and regressions for delayed materialization, supersession, active-leaf replacement, and out-of-bounds transient focus.

## Compatibility and migration

- Backward-compatible correctness patch. No settings, commands, Base schema, saved-date, note, task, or API migration is required.
- Minimum supported Obsidian remains 1.10.0.
- The version-1 `tps-calendar-open` URL contract is unchanged, so existing TishOS widgets use the fix without reconfiguration.

## Validation

- All 226 declared tests pass, including the focused mobile materialization, active-target replacement, supersession, renderer-settlement, and transient-boundary regressions.
- The required separate production build passed and reported the isolated test runtime unchanged. Source and deployed artifacts are byte-identical.
- After `Reload app without saving` in isolated Obsidian 1.13.7, the exact version-1 URI for `_archive/Calendar Day Bounds QA.base#Strict one-day filter QA` visibly opened August 15 even though the Base is explicitly filtered and saved to August 7. No failure notice recurred, and `tps_currentDate` remained `2026-08-07`.

## Known limitations

- The handoff remains local and navigation-only. The target Base must eventually exist in the currently loaded Obsidian vault; the bounded retry cannot download a permanently absent or unsynced file.
- Physical iPhone app-switch timing remains acceptance evidence for TishOS, not an automated desktop claim.
