# TPS Calendar Base 1.1.2 — Keep calendar titles and status settings aligned

Calendar now preserves the read-only `eventTitle` display of older occurrence notes after their Kind is migrated from a scalar to a YAML list. It asks GCM to identify the record instead of comparing the physical Kind field with a fixed string. Native-note selection also recognizes GCM's configured identity property, while retaining the historical `tpsId` read guard. Neither change rewrites note content.

**Advanced → Note linking and event status** now exposes the existing canceled external-event status setting. A blank setting shows no status label; Calendar no longer substitutes `wont-do`. If Controller also imports the feed, configure its canceled status label to the same value. The settings help text no longer assumes a fixed identity key or scalar Kind example.

This is a backward-compatible patch; minimum Obsidian remains **1.10.0**. Saved Base filters are editable in Obsidian and are not rewritten by this release. A future change to GCM's title property key also requires reviewing the Calendar Base view's title field and display mapping.
