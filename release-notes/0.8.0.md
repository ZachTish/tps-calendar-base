# TPS Calendar Base 0.8.0

This backward-compatible feature lets an embedded Calendar Base retain the exact day count authored in its view instead of always reducing the range to fit a narrow Markdown or Canvas pane.

- Set the view's **Embedded day count** option to **Keep configured days** to preserve one-, three-, five-, or seven-day ranges.
- The default remains **Fit available width**, so existing views keep their responsive behavior.
- Dedicated Calendar tabs, exact filter-derived ranges, and the direct dashboard renderer remain compatible.

Minimum Obsidian: 1.10.0. No Base or settings migration is performed.
