# TPS Calendar Base 1.0.1 — Use Obsidian Page Preview for created notes

Calendar no longer calls GCM's custom preview card. Saved `postCreateBehavior: preview` remains Preview. With GCM note-opening UI v2 or later, GCM owns Preview/Open/Stay. With older or unavailable GCM UI, Calendar's desktop Preview emits Obsidian's core `hover-link` event for the newly created note, while mobile Preview opens that note in Obsidian's native editor. Open and Stay retain their earlier actions. Calendar bypasses the older GCM native Base creation takeover so a v1 custom card cannot reclaim its creation path. No note content is migrated or rewritten.

This backward-compatible patch removes a custom-editor route without changing whole-note creation, Base defaults, event scheduling, or historical source navigation. Minimum Obsidian: **1.10.0**. The GCM core-preview update is also needed to remove GCM's shared custom card in other surfaces. An installed touch-preview action remains unverified, so the mobile Preview route deliberately uses the native editor rather than claiming a hover popover opens after creation.
