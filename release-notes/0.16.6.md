# TPS Calendar Base 0.16.6 — Keep navigation inside narrow panes

Calendar navigation now fits its pane even when the Obsidian window itself is wide. The date label can shrink with an ellipsis, while its full text remains accessible. Previous/Next have 44 × 44 px targets; Today and the date control are at least 44 px high.

Dedicated desktop Calendars follow their host height after resizing or zooming. Previously, the Calendar reused its old measured pixel height and could push its bottom controls below the pane. This fixes the existing sizing rules without adding state, observers or resize machinery. Embedded and mobile height branches are unchanged.

Backward-compatible patch. No settings, data, API or migration changes. Minimum Obsidian: **1.10.0**. Tested in **Obsidian Plugin Test Vault**, ready for the user's BRAT pull. Production has not been modified.
