# 0.12.0 — Current-time labels

Adds the current hour and minute above the red Calendar now line in dedicated,
embedded and continuous time grids. The label follows the plugin's 12/24-hour
setting; the existing per-view Show now indicator setting controls both surfaces.
This backward-compatible feature receives a minor version. Minimum Obsidian:
1.10.0. No settings migration, saved-note change, command or new API is required.

FullCalendar 6.1.19 passes a day-column midnight to its line-content hook, so the
label owns a small minute-aligned display timer instead. It catches up on focus
and visibility return, and removes its timer/listeners on unmount. It never
refreshes event data or reads the vault. FullCalendar still positions the line.

Validation: 288/288 declared Node tests, zero failures/skips, TypeScript and the
mandatory separate production build. Tests cover 12/24-hour formatting, noon and
midnight, timer alignment, sleep recovery, cleanup, both renderer hooks and the
existing view visibility override. Test-vault Obsidian 1.14.1 reloaded 0.12.0;
a synthetic Calendar showed the readable red label above its line, and it advanced
from 3:48pm to 3:49pm without an event refresh. iPhone/touch acceptance is not claimed.
Existing unrelated source candidates were excluded using a contained release
worktree. Production was not deployed or modified.

Tested in the isolated test vault and ready for the user's BRAT pull.
