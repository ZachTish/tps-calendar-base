# TPS Calendar Base 1.1.3 — One owner for paired edit refreshes

Backward-compatible patch; minimum Obsidian remains 1.10.0. Tested in the isolated Test Vault and ready for the user's BRAT pull and acceptance. Production remains unchanged.

## Change

An immediate GCM explicit-action/Calendar-refresh notification now clears and consumes Calendar's already-pending refresh timer before running its forced update. GCM's paired FilesUpdated notification had left that timer alive, causing a second full pass over the same settled query. No cross-channel cache or deduplication state is introduced.

Later MetadataCache changes and Core Bases query notifications remain independent refresh owners. FilesUpdated-only automation still schedules its forced update. Existing single-flight, navigation-epoch, visibility, metadata fast-display and scroll-preservation behavior remains unchanged. No settings, schema, note writes, provider configuration, migration or automatic repair changes.

## Tests

`scripts/test-calendar-refresh-routing.mjs` executes the shipped registration, scheduling, immediate-refresh, metadata-listener, native-mode update, single-flight and navigation methods. Host events/timers and title/date/style/DOM helpers are mocked. Twelve checks pass; four failed against 1.1.2 before the fix. A settled paired action over 1,000 synthetic query rows decreases from two full passes, two Base-filter reads, 2,000 metadata checks and two render requests to one of each pass/read/render and 1,000 metadata checks. Late metadata and Bases arrivals retain a required later pass. These counts are not an installed UI benchmark.

The versioned full declared suite passes all 353 checks across 30 files, with zero failures, cancellations or skips. TypeScript, the suite's build and the mandatory separate final build pass. Build-only review gates used `TPS_NO_DEPLOY=1`; the final ordinary build deploys only shipped Calendar files to the Test Vault. Named `plugin:reload` verifies installed 1.1.3. A final post-documentation ordinary build preserves the already-validated artifact bytes and runtime data.
