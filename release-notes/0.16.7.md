# TPS Calendar Base 0.16.7 — Keep Canvas handling inside Canvas

Ordinary Markdown Calendar embeds no longer activate the global geometry override and mouse interception intended for Canvas scaling. The existing effect now checks the already-detected Canvas ancestry and reruns when that detection changes. Real Canvas embeds keep the existing scaling and shared cleanup behavior.

This is a backward-compatible scope correction: two changed runtime lines, with no new state, caches, listeners, timers, settings, writes or migration. Minimum Obsidian: **1.10.0**. Tested in **Obsidian Plugin Test Vault** and ready for the user's BRAT pull; production has not been modified.

## Validation

- Four new actual-source regressions, three failing against 0.16.6. They cover 50 ordinary mounts/1,000 geometry reads without Canvas inspections, late Canvas detection, multiple Canvas owners, ordinary/Canvas isolation and missing/nonembedded hosts. DOM geometry and effect scheduling are mocked.
- All **354** declared tests pass, with zero failures/skips/cancellations. TypeScript, separate production build, test deployment and named Calendar-only reload pass.
- Installed ordinary embed: all 48 synthetic events render, with the native global geometry function unchanged. Actual Canvas at 43.3% scale: all 48 events render; scaled visual row width matches the unscaled measurement multiplied by Canvas scale. Next shows the following day with 0 events; Today restores 48. Closing Canvas restores native geometry.
- Canvas was disabled and its settings file absent. QA temporarily enabled it with in-memory default settings, suppressing setup/teardown config-save requests. The original methods, enabled set and saved core configuration were restored; no Canvas config file was created. A zoom-button attempt did not change scale and is excluded from successful interaction coverage. Physical iPhone and scaled event drag/resize are not certified by this check.
- All 53 existing fixture files remain byte-identical. The one new Canvas fixture preserves its graph, with native serialization formatting. All 54 files archived, original view restored, eight plugin settings unchanged, Calendar registry empty and temporary instrumentation removed.
- Foreground ordinary embedded opening measured 700 ms before / 731 ms after in small instrumented samples. No startup speedup or native-equivalence claim is made. The confirmed improvement is the scope/lifetime of global interception; initial Base processing and rendering remain separate costs.
